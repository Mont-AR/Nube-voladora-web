# Lumen Studio

Landing de estudio creativo construida con [Astro](https://astro.build): hero con escena 3D interactiva en Three.js (agua reflectante con ondas, esfera iridiscente, ciclo día/atardecer, post-procesado), cursor personalizado, grano animado, menú a pantalla completa, grilla de proyectos, sección de estudio y footer de contacto.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build
```
