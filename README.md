# Lumen Studio

Landing de estudio creativo construida con [Astro](https://astro.build): hero con escena surrealista hecha en CSS/SVG, cursor personalizado, grano animado, menú a pantalla completa, grilla de proyectos, sección de estudio y footer de contacto.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build
```
